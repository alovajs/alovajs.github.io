---
title: wormhole API
---

`@alova/wormhole` 的 API 与命令行已由其官方、通用化的继任者 **[worma](https://worma.js.org)** 接替。关于命令与编程接口，请参见 worma 的 [CLI 命令](https://worma.js.org/docs/cli-commands) 与 [API 参考](https://worma.js.org/docs/api/core-functions)。若需从 wormhole 迁移，请参见 [从 wormhole 迁移](https://worma.js.org/docs/migration/from-wormhole)。
