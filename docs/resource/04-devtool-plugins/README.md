title: Plugin Development Guide
---

worma's plugin system replaces `@alova/wormhole`'s devtool plugins. Learn how to use the built-in plugins or build your own in the worma [Plugin System](https://worma.js.org/docs/plugin-system) guide (see also the [built-in plugins](https://worma.js.org/docs/plugin-system/builtin-plugins) overview).
