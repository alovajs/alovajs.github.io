title: wormhole API

`@alova/wormhole`'s API and CLI have been succeeded by **[worma](https://worma.js.org)** — its official, generalized successor. For commands and programmatic APIs, see the worma [CLI commands](https://worma.js.org/docs/cli-commands) and [API reference](https://worma.js.org/docs/api/core-functions). Migrating from wormhole? See [Migrating from wormhole](https://worma.js.org/docs/migration/from-wormhole).
