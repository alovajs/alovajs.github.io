# The alova doc Website

The official documentation website of [alova](https://alova.js.org), built with Docusaurus.

## What is alova?

alova (pronounced /əˈləʊva/) is a **fullstack request strategy library**. It treats a request as a scenario with a lifecycle — not a one-time instantaneous call — and organizes the request logic you've hand-written countless times, such as pagination, forms, uploads and authentication, into a complete whole we call **request strategies**.

You don't have to throw away the axios or fetch you already know: alova builds right on top of your existing request library and takes over the request logic you keep rewriting. The same API set runs across React, Vue, Svelte, Solid, mini-programs and the server, so you learn it once and use it everywhere.

With request strategies, details that decide the user experience — input debouncing, cache hits for identical conditions, discarding stale responses, automatic retry on failure, next-page preloading — come as configuration instead of hand-written code, which also makes the request layer easy for AI coding assistants to review.
